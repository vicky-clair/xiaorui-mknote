# MKNote Next — 本地优先加密桌面知识库

**MKNote Next** 是一款基于 **.NET 10 + WinUI 3 + SQLCipher AES-256 + WebView2** 构建的现代 Windows 桌面笔记与个人知识库软件。  
核心坚持 **100% 本地离线优先、零强制云账号、全库加密落盘（仅可通过本应用打开）**，同时内置 **富文本（HTML）** 与 **Markdown** 双文档引擎，兼顾日常图文摘录、代码与公式记录、双链知识图谱与端到端加密（E2EE）群晖 NAS / WebDAV 跨设备同步。

---

## 一、核心功能特性

### 1. 全链路本地加密与防崩溃保护
- **整库 + 逐对象双重加密**：底层采用 **SQLCipher（AES-256）** 全库加密，同时每篇笔记正文、截图、手动插入图片、附件与全局背景图均以 **AES-256-GCM** 独立密文 BLOB 存入 `vault.db`，磁盘不生成任何明文 `.md` / `.html` / `.png` 缓存文件。
- **密钥与访问安全**：本地 256 位主密钥 `vault.key` 默认由 Windows **DPAPI**（当前用户绑定）加密保护；可选便携模式（程序旁 `Data/` 目录随身携带）。支持**本地应用锁**（PBKDF2-SHA256 + Windows Hello 生物识别/PIN + 空闲自动锁定）以及**单篇笔记独立密码加密**。
- **防崩溃恢复日志（Crash-Safe Journal）**：编辑过程中自动防抖保存并实时写入加密恢复日志（`recovery/*.mkr`）。即使遭遇系统断电或异常闪退，下次启动时会自动检测并无损恢复崩溃前最后输入的内容。
- **回收站隐私门禁**：移入回收站的文档默认锁定正文内容不予展示，仅允许「恢复」或「永久删除」。
- **严格单实例运行**：通过 Win32 命名互斥量（Mutex）与命名管道（NamedPipe）禁止双开多开；重复启动时自动唤醒已在前台或托盘中的现有窗口。

### 2. 双文档引擎（富文本 + Markdown）
- **富文本编辑器（TipTap 2 / ProseMirror）**
  - 所见即所得排版：字体、字号、加粗/斜体/下划线/删除线、标题层级、对齐方式、文字高亮与着色、任务清单、表格、代码块、分割线。
  - 实用文本处理工具：支持大小写转换、去除行尾空白、行排序、行去重、快速插入当前日期/时间、统计选中字数；常用按钮外的高级操作自动收纳在 `>>` 折叠工具条中，界面简洁清爽。
  - 粘贴体验优化：从 Windows 网页或文档复制时保持良好的图文兼容性，普通文本默认按纯文本规范粘贴，避免杂乱样式污染；支持直接粘贴或拖拽图片自动加密入库。
- **Markdown 编辑器（CodeMirror 6）**
  - **行内实时预览（Live Preview）** 与 **沉浸阅读模式（Reading）** 一键切换（`Ctrl+E`），支持顺畅滚动长文档。
  - 完整语法扩展：YAML Frontmatter 属性、双向链接 `[[笔记名#标题|别名]]` 自动补全与改名自动更新、反向链接面板、大纲目录、Callout 提示块、**KaTeX 数学公式**、**Mermaid 流程图/时序图/架构图**、任务列表、表格、脚注与代码块语法高亮。
  - **知识图谱（Graph View）**：基于 Canvas 的力导向双链关系图，支持筛选、缩放、拖拽及双击跳转。
  - **深度 Vim 模式**：支持 Normal / Insert / Visual / Ex（`:w`、`:noh`、`:%s/旧/新/g`、`/搜索`）完整命令，底部状态栏实时显示当前 Vim 模式与按键缓冲区；修复了图片左右光标定位与图片删除交互。

### 3. 截图、图片与知识管理
- **内置区域截图（`Ctrl+Shift+A`）**：纯内存多显示器高 DPI 框选截图，不落盘临时文件，松开鼠标后直接加密存入数据库并插入当前文档。
- **完整文件夹与标签体系**：支持自由新建、重命名、删除**任意文件夹（包含默认文件夹）**；每篇笔记顶部提供**复制到文件夹**、**移动到文件夹**、置顶、星标、删除按钮；富文本与 Markdown 均支持多标签管理与按标签筛选。
- **全库精准检索（`Ctrl+K`）**：支持跨所有文档（含超长正文深处）实时搜索，精准匹配特殊符号（如 `C#`、`->`、`[[双链]]`、`$100`、`==`、`::`）。
- **Word 风格字数统计**：状态栏实时展示按微软 Word 算法统计的**总字数（中日韩字符 + 西文/数字单词）**，悬停或点击查看不含空格字符数、含空格字符数、段落数、行数及当前选区字数。
- **自定义外观与多语言**：
  - 支持 **简体中文 / English / 日本語** 三语一键无缝切换。
  - 设置中可分别调用 Windows **本机已安装的系统字体**作为「界面字体」与「文档正文字体」。
  - 支持单篇文档背景色与**全局文档背景图片**（加密入库，支持填充 `cover`、适应 `contain`、拉伸 `stretch`、平铺 `tile`、居中 `center` 模式）。
- **系统集成**：支持独立桌面置顶便签窗、Windows 开机自启（静默驻留托盘）、关闭按钮最小化到托盘（单击托盘图标显示/隐藏主窗）。

### 4. 端到端加密同步（支持群晖 NAS 与 WebDAV）
- 所有同步数据在离开本机前使用用户独立设置的 **E2EE 主同步口令** 经 **PBKDF2-SHA256 + AES-256-GCM** 加密，远端 NAS / 网盘仅存密文（`.mke` / `.mkb`）。
- 支持 4 种同步目标，每种均在同步窗口内置了详细的三语操作指南：
  1. **群晖 NAS — WebDAV Server**（推荐，支持 HTTPS 5006 与局域网自签名证书信任）
  2. **群晖 NAS — 局域网 SMB 共享 / 映射盘**（如 `\\192.168.1.100\homes\MKNoteSync` 或 `Z:\MKNoteSync`）
  3. **通用 WebDAV 云存储**（坚果云、Nextcloud、Alist、ownCloud 等）
  4. **本地 / 第三方同步盘目录**（如 Synology Drive / OneDrive 本地同步文件夹）
- **零数据丢失冲突策略**：当多设备同时修改同一篇文档时，自动保留双方改动并生成冲突副本，绝不静默覆盖正文。

### 5. 多格式本地导入与导出
- **导入**：支持导入 `.mknote` 归档文件（自动提取分类、标签、正文与内嵌图片）、标准 `.enex` / `.notes` 归档（流式解析大文件并提取 Base64 内嵌图片）、批量 HTML 文件夹（自动将本地相对路径图片加密入库）、Markdown 文件夹与旧版 SQLite 数据库。
- **导出**：支持导出单篇或整库为 Markdown 文件夹、单篇 HTML、TXT 与原生高质量 PDF；支持全库离线加密备份（`.mkbackup`）。

## 二、日常使用指南

### 1. 快速上手
1. **新建文档**：点击左侧顶部「新建」按钮，可选择创建 **Markdown 笔记**、**富文本笔记**、**从模板新建**（10 套内置模板，支持 `{{date}}` / `[%date%]` 自动展开）或**独立便签**。新建的空白文档不会在正文重复填入标题。
2. **组织文档**：
   - 在左侧「笔记本」栏右键或点击「+」可新建/重命名/删除文件夹（默认文件夹亦可自由删除）。
   - 打开任意笔记，在编辑器右上角工具栏可直接点击 **「复制到」**、**「移动到」**、**置顶**、**星标**、**删除**，或在标题下方直接增删标签。
3. **截图与插图**：
   - 在任意笔记编辑状态下，按全局热键 `Ctrl+Shift+A`（或点击顶部/托盘截图按钮），框选屏幕区域后松开鼠标，截图会自动加密入库并插入光标处。
   - 手动插入本地图片或粘贴剪贴板图片同样会自动转存至加密数据库。
4. **查看与自定义快捷键**：
   - 点击右上角 `...` 菜单，可分别打开 **「Vim 快捷键指南与自定义」** 与 **「Markdown 语法与快捷键」** 窗口。
   - 可按分类检索命令并自定义个人键位；系统内置的固定保护快捷键（如 `Ctrl+C`/`V`/`X`/`Z`/`S`/`K`/`E`、`Ctrl+Shift+A`、`Esc`）受 `ShortcutGuard` 严格锁定，不可被误覆盖。

### 2. 配置群晖 NAS 端到端加密同步（推荐步骤）
1. 在群晖 DSM「套件中心」安装并启动 **WebDAV Server**，启用 **HTTPS（默认端口 5006）**，并在「控制面板 → 共享文件夹」创建一个专用目录（例如 `/MKNoteSync`）且授予对应账号读写权限。
2. 打开 MKNote Next → 点击右上角 `...` → **「同步与加密配置」**。
3. 同步目标选择 **「群晖 NAS (WebDAV)」**：
   - **服务器地址**：填写 `https://群晖局域网IP:5006`（或公网 DDNS 地址）。
   - **远端目录**：填写 `/MKNoteSync`。
   - **账号与密码**：输入群晖账号密码；若局域网使用群晖默认自签名证书，请勾选 **「信任局域网自签名 HTTPS 证书」**。
   - **端到端加密（E2EE）**：保持开启，并输入您的 **独立 E2EE 主加密口令**（多台设备必须输入完全相同的口令）。
4. 点击 **「测试连接」** 确认读写正常，随后点击 **「立即同步」**，并按需开启定时自动同步（5 / 15 / 30 / 60 分钟）。

> **局域网免配置替代方案**：若电脑与群晖处于同一局域网，也可直接在同步目标选择 **「群晖 NAS (SMB 共享)」**，路径填入 `\\192.168.1.100\homes\MKNoteSync` 即可同步。

### 3. 常用固定快捷键速查
| 快捷键 | 功能说明 |
| :--- | :--- |
| `Ctrl + K` | 聚焦全库精确搜索框（支持符号精准搜索） |
| `Ctrl + Shift + A` | 全局区域屏幕截图并加密插入当前笔记 |
| `Ctrl + E` | Markdown 行内预览 / 沉浸阅读模式切换 |
| `Ctrl + S` | 立即保存并创建本地历史版本快照 |
| `Ctrl + J` / `Ctrl + P` | Vim 模式下快速切换下一篇 / 上一篇笔记 |
| `Esc` | 退出 Vim 输入/可视模式，或取消区域截图 |

## 三、重要安全与使用注意事项

1. **妥善保管 `vault.key` 与备份文件（重装系统前必读）**
   - 标准安装模式下，数据默认保存在 `%LOCALAPPDATA%\MKNoteNext\Vault\`（包含 `vault.db` 与 `vault.key`）。
   - 由于 `vault.key` 默认绑定了当前 Windows 用户的 DPAPI 凭证，**重装系统、更换电脑或重建 Windows 账户后，直接拷贝旧 `vault.db` + `vault.key` 将无法解密！**
   - **正确迁移方式**：请务必在换机/重装前使用应用内的 **「加密同步」** 或 **「备份 / 导出」** 功能完整导出数据，或使用绿色便携模式（在程序目录新建 `Data` 文件夹存放便携库）。
2. **牢记 E2EE 同步口令与单篇笔记密码**
   - 本软件为 100% 零知识本地加密架构，**不存在任何后台服务器或“找回密码”渠道**。一旦遗忘端到端同步主口令或单篇笔记加密密码，对应密文在数学上无法恢复，请务必妥善记录口令（如使用密码管理器）。
3. **自动保存与单篇容量**
   - 编辑内容会在停顿约 0.5 秒后自动加密保存，无需频繁手动按 `Ctrl+S`；单篇文档支持混合写入大量文本、表格、代码块、公式、流程图与高分辨率图片，图片以去重 BLOB 分表存储，不会因内容丰富造成截断或丢失。
4. **运行环境要求**
   - 操作系统：Windows 10（1809 / Build 17763 及以上）或 Windows 11（64 位 x64）。
   - 运行时：需系统自带或已安装 **Microsoft Edge WebView2 Runtime**（Windows 11 默认内置）。

## 四、开发者构建与打包指南

### 1. 环境准备
- **.NET 10 SDK**（含 Windows Desktop SDK）
- **Node.js 20+** 与 npm
- **Inno Setup 6**（仅制作 Windows `.exe` 安装包时需要）

### 2. 项目目录结构
```text
MKNoteNext.sln
├── src/
│   ├── MKNote.Core/         # 领域模型、Markdown 解析器、Word 字数统计、三语本地化、快捷键守卫
│   ├── MKNote.Security/     # DPAPI/便携主密钥管理、PBKDF2 + AES-256-GCM 加解密引擎
│   ├── MKNote.Storage/      # SQLCipher 整库仓储、全库符号检索、加密恢复日志、版本快照
│   ├── MKNote.Sync/         # 端到端加密同步引擎、WebDAV / SMB / 本地目录传输层与三语指南
│   ├── MKNote.Migration/    # .mknote / .enex / HTML / Markdown / 旧库多格式迁移服务
│   ├── MKNote.EditorWeb/    # Vite + TypeScript + TipTap 2 + CodeMirror 6 + KaTeX + Mermaid
│   └── MKNote.App/          # WinUI 3 桌面主程序、托盘、截图、单实例守护、系统字体与各功能弹窗
├── tests/
│   └── MKNote.Tests/        # xUnit 单元测试（加密、存储、检索、同步、导入导出）
├── installer/
│   └── MKNoteNext.iss       # Inno Setup 6 Windows x64 安装包脚本
└── docs/
    └── MKNote_Next_Development_Spec.md  # 完整架构与开发规范文档
```

### 3. 编译与运行
```powershell
# 1. 构建前端离线双内核编辑器（产物自动输出到 src/MKNote.App/Assets/EditorWeb）
cd src/MKNote.EditorWeb
npm install
npm run build
cd ../..

# 2. 运行全部单元测试
dotnet test tests/MKNote.Tests/MKNote.Tests.csproj

# 3. 编译 WinUI 3 桌面应用（x64）
dotnet build src/MKNote.App/MKNote.App.csproj -c Debug -p:Platform=x64
```

### 4. 发布自包含安装包（Release x64）
```powershell
# 1. 发布自包含目录
dotnet publish src/MKNote.App/MKNote.App.csproj -c Release -r win-x64 --self-contained true -p:Platform=x64 -o dist/publish-x64

# 2. 使用 Inno Setup 6 生成安装包（输出至 dist/MKNoteNext_Setup_v1.0.0_x64.exe）
iscc installer/MKNoteNext.iss
```
