# MKNote Next — 本地优先加密桌面知识库

**MKNote Next** 是一款基于 **.NET 10 + WinUI 3 + SQLCipher AES-256 + WebView2** 构建的现代 Windows 桌面笔记与个人知识库软件。  
核心坚持 **100% 本地离线优先、零强制云账号、全库加密落盘（仅可通过本应用打开）**，同时内置 **富文本（HTML）** 与 **Markdown** 双文档引擎，兼顾日常图文摘录、待办清单、代码与公式记录、双链知识图谱、批量管理与端到端加密（E2EE）群晖 NAS / WebDAV 跨设备同步。

---

## 一、核心功能特性

### 1. 全链路本地加密与防崩溃保护
- **整库 + 逐对象双重加密**：底层采用 **SQLCipher（AES-256）** 全库加密，同时每篇笔记正文、屏幕截图、手动插入图片、附件与全局背景图均以 **AES-256-GCM** 独立密文 BLOB 存入 `vault.db`，磁盘不生成任何明文 `.md` / `.html` / `.png` 缓存文件。
- **密钥与访问安全**：本地 256 位主密钥 `vault.key` 默认由 Windows **DPAPI**（当前用户绑定）加密保护；可选便携模式（程序同级创建 `Data/` 目录即可随身携带）。支持**本地应用锁**（PBKDF2-SHA256 + Windows Hello 生物识别/PIN + 空闲自动锁定）以及**单篇笔记独立密码加密**。
- **防崩溃恢复日志（Crash-Safe Journal）**：编辑过程中自动防抖保存并实时写入加密预写恢复日志（`recovery/*.mkr`）。即使遭遇系统断电或异常闪退，下次启动时会自动检测并无损恢复崩溃前最后输入的内容。
- **回收站隐私门禁**：移入回收站的文档默认锁定正文内容不予展示，仅允许「恢复」或「彻底删除」。
- **严格单实例运行**：通过 Win32 命名互斥量（Mutex）与命名管道（NamedPipe）禁止双开多开；重复启动时自动唤醒已在前台或托盘中的现有窗口。

### 2. 双文档引擎（富文本 + Markdown）
- **富文本编辑器（TipTap 2 / ProseMirror）**
  - **排版与字体控制**：内置**系统字体下拉框**与**字号下拉框（12px–32px）**——**选中文本时**可对局部片段单独修改字体与字号（支持同文档多字体混排），**未选中文本时**即时调整全局默认正文并自动保存。另支持标题层级、加粗/斜体/下划线/删除线、文字颜色、4 色高亮与清除、对齐方式、待办清单、表格（增删行列）、代码块、引用与行内查找替换。
  - **实用文本处理工具（`»` 扩展栏）**：支持行升序排序、删除重复行、清除行尾空格、大小写转换、快速插入时间戳。
  - **智能粘贴与待办兼容**：从网页或外部文档复制粘贴时自动保留图片（加密入库）与待办复选框，普通文本按纯文本保留完整换行，避免杂乱样式污染。
- **Markdown 编辑器（CodeMirror 6）**
  - **三态视图切换**：支持 **行内实时预览（Live Preview）**、**左右分屏（Split）** 与 **沉浸阅读模式（Reading，`Ctrl+E`）**，阅读模式支持长文档顺畅滚动。
  - **工具栏字体与语法扩展**：工具栏内置**系统字体与字号（12px–32px）快捷切换**、H1–H3 标题、加粗/斜体/删除线/高亮、行内代码与代码块、待办复选框、双链 `[[笔记名#标题|别名]]` 自动补全与改名联动、表格、YAML Frontmatter 属性、Callout 提示卡、**KaTeX 数学公式**与 **Mermaid 流程图/时序图/架构图**。
  - **知识图谱（Graph View）**：基于 Canvas 的力导向双链关系图，支持节点筛选、拖拽缩放与双击跳转，并支持点击 **「← 返回文档」**、按 **`Esc`** 或再次点击 **「知识图谱」** 一键切回当前文档。
  - **深度 Vim 模式**：支持 Normal / Insert / Visual / Ex（`:w`、`:noh`、`:%s/旧/新/g`、`/搜索`）完整命令，底部状态栏实时显示当前 Vim 模式与按键缓冲区；支持图片左右光标辅助定位与删除。

### 3. 灵活三栏界面、批量管理与系统集成
- **灵活可拖动三栏布局**：左侧导航栏、中间笔记列表栏、右侧大纲/反链/附件抽屉之间均配备原生水平双箭头（`↔`）可拖动分隔条，支持鼠标自由拖动放缩宽度，**双击分隔条**一键恢复默认宽度，并自动持久化记忆您的布局宽度；列表筛选栏（**全部 / MD / 富文本**）采用独立放大字号分段展示。
- **笔记本、标签与高效批量删除**：
  - 支持自由新建、重命名、删除**任意文件夹（包含默认文件夹）**；每篇笔记顶部提供**复制到**、**移动到**、置顶、星标、删除按钮；富文本与 Markdown 均支持多标签管理与筛选。
  - 笔记列表右上角提供 **「批量多选（☑）」** 开关：支持复选框逐项多选、`Shift + 点击` 区间连选、**全选**、**反选**、一键**事务级批量删除**（在回收站内同时支持**批量恢复**与**批量彻底删除**），处理数百篇导入文档零卡顿。
- **纯内存区域截图（`Ctrl+Shift+A`）**：支持多显示器高 DPI 框选截图，不落盘任何临时明文图片，直接加密入库并插入当前光标位置。
- **全库精准符号检索（`Ctrl+K`）**：跨所有文档（含长正文深处）实时检索，精准匹配特殊符号（如 `C#`、`->`、`[[双链]]`、`$100`、`==`、`::`）。
- **精准字数统计**：底部状态栏实时展示**总字数（中日韩按字计、西文/数字按词计）**，点击可查看字符数（计/不计空格）、段落数、行数及当前选区统计。
- **三语切换、特色背景与安全系统字体**：支持 **简体中文 / English / 日本語** 一键热切换；系统字体枚举自动过滤图标/符号类字体并附加中/英/日安全回退链；提供**浅色 8 套 + 深色 8 套专属特色文档背景**（如浅色「纯净象牙白 / 护眼豆沙绿 / 温暖羊皮纸 / 清透天青蓝」、深色「午夜纯黑 / 暗夜墨松绿 / 深海星空蓝 / 烘焙咖啡棕 / 星云暗夜紫 / 酒红勃艮第 / 石墨高级灰 / 复古黑板青」）以及在浅/深色下均清晰可见的 **5 种纸张纹理**（纯色/横线/方格/点阵/纸感），并支持**全局加密背景图**（填充/适应/拉伸/平铺/居中）。
- **桌面原生能力**：支持独立置顶便签窗、Windows 开机自启（静默驻留托盘）、关闭按钮最小化至系统托盘（单击托盘图标显示/隐藏主窗）。

### 4. 端到端加密同步与多种备份策略（群晖 NAS / WebDAV）
- 所有同步数据在离开本机前使用用户独立设置的 **E2EE 主同步口令** 经 **PBKDF2-SHA512 (210,000 次迭代) + HKDF-SHA256 分层会话密钥 + AES-256-GCM** 加密，远端仅存密文（`.mke` / `.mkb`），配合加密增量索引清单（`meta/manifest.mke`）与 4 路并发传输，二次同步秒级完成。
- 内置 4 种同步目标与对应三语配置向导：
  1. **群晖 NAS — WebDAV Server**（推荐，支持 HTTPS 5006 与局域网自签名证书信任）
  2. **群晖 NAS — 局域网 SMB 共享 / 映射盘**（如 `\\192.168.1.100\homes\MKNoteSync` 或 `Z:\MKNoteSync`）
  3. **通用 WebDAV 服务器 / 云盘**（支持标准 WebDAV 协议的私有服务器与网盘）
  4. **本地目录 / 移动存储同步目录**（本地同步文件夹、U 盘或移动硬盘目录）
- **4 种同步与备份策略（可在同步窗口自由切换）**：
  - **双向同步（默认，同步删除）**：两端增量合并、冲突自动保留副本；通过加密删除墓碑（`meta/tombstones.mke`）联动清理远端与其他设备的已彻底删除笔记，**彻底解决删除后再同步复活的问题**。
  - **保留两者（只增不删）**：双端保守合并，冲突保留副本，不因删除操作清理远端文件。
  - **以本地为主（单向镜像备份）**：严格以本机为准覆盖远端并自动清理远端多余/残留文件，绝不向本机拉回覆盖。
  - **以远端为主（从云端恢复）**：从远端完整拉取并覆盖本机同名笔记，同步应用远端删除记录，不修改远端数据。

### 5. 多格式本地导入与导出
- **导入（内置严格判重防重复导入）**：
  - 导入前严格比对**标题 + 文档格式 + 全文及全部内嵌图片 SHA-256 哈希**，仅在 100% 确认完全一致时自动跳过并弹窗提示重复清单（绝不误伤同名但正文/图片有改动的文档，也不会产生空分类）。
  - **Markdown 文件夹**：按目录树自动重建多级笔记本（智能识别 UTF-8 / UTF-16LE / GB18030）。
  - **网页 HTML 文件夹**：批量导入 `.html`/`.htm`，自动将同级相对路径图片与 Base64 内嵌图片加密入库，并将原生待办复选框（`<input type="checkbox">` 等）自动转换为可交互待办清单。
  - **单文件归档（`.mknote`）**：原生解析元数据（分类/标签）、正文、内嵌图片与待办复选框并加密入库。
  - **本地 SQLite 笔记库（`.db`）**：导入通用结构化分类与笔记条目。
- **导出与备份**：
  - **单篇精准导出**：支持在编辑区顶部、笔记列表右键菜单或「更多 → 备份与导入导出」导出单篇笔记；**Markdown 笔记仅导出 `.md`**（含图片时同级生成 `assets/` 相对路径），**富文本笔记导出为独立单文件 `.html`**（图片自动 Base64 内嵌，发给他人或离线双击浏览器打开永不丢图）。
  - **指定分类单独导出**：在左侧笔记本列表右键或点击 `...` → **「导出此笔记本 (MD + HTML)...」**，自动按笔记格式分别导出 `.md` 与 `.html` 并还原内嵌图片，存在子笔记本时可自由选择“包含子笔记本（保留多级目录树）”或“仅导出当前层级”。
  - **多选批量导出与全库导出**：支持批量多选「导出所选」与全库按多级目录导出（自动同名防覆盖），以及全库离线加密备份（`.mkbackup`）。

## 二、日常使用指南

### 1. 快速上手
1. **新建笔记**：点击左上角「新建」可创建 **Markdown**、**富文本**、**内置模板笔记**（10 套模板支持 `{{date}}` 自动展开）或**桌面便签**。空白新文档不会在正文重复插入标题。
2. **界面自由调节**：
   - 将鼠标移至三个侧边栏边缘出现 `↔` 双箭头时，按住左键即可拖动调宽；**双击分隔条**可恢复默认宽度。
   - 在编辑器工具栏直接选择任意**系统字体**与**字号**；富文本下先选中文字再选字体/字号即可局部排版。
3. **批量清理大量文档**：
   - 点击笔记列表右上角的 **多选图标（☑）** → 可使用 **全选** / **反选** / 手动勾选 / `Shift + 点击` 连选 → 点击 **删除所选** 一键批量移入回收站（在回收站中同样可多选后批量恢复或彻底删除）→ 点击 **完成** 或按 `Esc` 退出多选模式。
4. **截图与加密插图**：按 `Ctrl+Shift+A` 框选屏幕即可直接加密入库并插图；手动插入或粘贴剪贴板图片同样自动加密存入数据库。
5. **查看与自定义快捷键**：点击右上角 `...` 菜单可打开 **「Vim 快捷键指南与自定义」** 与 **「Markdown 语法与快捷键指南」**，系统核心保留热键受 `ShortcutGuard` 保护不可被误覆盖。

### 2. 配置群晖 NAS 端到端加密同步
1. 在群晖 DSM「套件中心」安装并启用 **WebDAV Server**，开启 **HTTPS（端口 5006）**，创建共享目录（如 `/MKNoteSync`）并赋予对应账号读写权限。
2. 在 MKNote Next 中点击右上角 `...` → **「加密同步（群晖 NAS / WebDAV）」**。
3. 选择 **「群晖 Synology NAS — WebDAV Server」**：
   - 填写服务器地址（如 `https://192.168.1.100:5006`）与远端目录（`/MKNoteSync`）；
   - 输入群晖账号密码；局域网自签名证书请保持勾选「允许局域网自签名 HTTPS 证书」；
   - 保持开启 **端到端加密（E2EE）**，设置您的 **E2EE 同步主密码**（多台电脑必须一致）。
4. 点击 **「测试连接」** 确认成功，再点击 **「立即加密同步」**，并按需开启定时自动同步（5 / 15 / 30 / 60 分钟）。

> **局域网直连替代方案**：同一局域网下也可选 **「群晖 NAS — SMB 共享目录」**，路径填写 `\\192.168.1.100\homes\MKNoteSync` 即可高速同步。

### 3. 常用固定保护快捷键
| 快捷键 | 功能说明 |
| :--- | :--- |
| `Ctrl + K` | 聚焦全库精准符号与文本搜索框 |
| `Ctrl + Shift + A` | 全局区域截图并加密插入当前文档 |
| `Ctrl + E` | Markdown 行内预览 / 阅读模式切换 |
| `Ctrl + S` | 立即保存并创建本地历史版本快照 |
| `Ctrl + H` | 富文本行内查找与替换 |
| `Ctrl + J` / `Ctrl + P` | Vim 模式下快速切换下一篇 / 上一篇笔记 |
| `Esc` | 退出 Vim 输入/可视模式、退出知识图谱、退出批量多选或取消截图 |

## 三、重要安全与使用注意事项

1. **重装系统或换机前务必先同步或导出（重要！）**
   - 标准安装模式下，数据默认位于 `%LOCALAPPDATA%\MKNoteNext\Vault\`（包含 `vault.db` 与 `vault.key`）。
   - `vault.key` 默认绑定当前 Windows 账户的 **DPAPI** 凭证，**重装系统、更换电脑或重建 Windows 账户后，仅拷贝旧 `vault.db` + `vault.key` 将无法解密**。
   - **正确迁移方式**：换机或重装前请通过 **端到端加密同步（群晖 NAS / WebDAV）** 或 **导出 Markdown 文件夹** 完整迁出数据；若需 U 盘随身携带，请在程序同级目录新建 `Data` 文件夹启用绿色便携模式。
2. **妥善保管 E2EE 同步口令与单篇笔记密码**
   - 本软件为 100% 零知识本地加密架构，**无后台服务器、无找回密码渠道**。请使用密码管理器或离线安全方式妥善保存 E2EE 主口令与单篇加密密码。
3. **自动保存与单篇大容量支持**
   - 输入停顿约 0.25 秒即自动写入加密预写日志并提交数据库；图片以内容去重 BLOB 分表存储，单篇文档可安全混排大量文本、表格、代码块、公式、流程图与高分辨率图片。
4. **运行环境要求**
   - 操作系统：**Windows 10（1809 / Build 17763 及以上）** 或 **Windows 11（64 位 x64）**（当前桌面外壳基于 WinUI 3，暂仅支持 Windows x64）。
   - 运行时：系统需具备 **Microsoft Edge WebView2 Runtime**（Windows 11 已默认内置）。

## 四、开发者构建与打包指南

### 1. 环境准备
- **.NET 10 SDK**（含 Windows Desktop 工作负载）
- **Node.js 20+** 与 npm
- **Inno Setup 6**（仅制作 Windows `.exe` 安装包时需要）

### 2. 项目目录结构
```text
MKNoteNext.sln
├── src/
│   ├── MKNote.Core/         # 领域模型、Markdown 分析器、Word 字数统计、三语词条、快捷键守卫
│   ├── MKNote.Security/     # DPAPI/便携主密钥管理、PBKDF2 + AES-256-GCM 加解密引擎
│   ├── MKNote.Storage/      # SQLCipher 整库仓储、全库符号检索、事务批量删除、防崩溃恢复日志
│   ├── MKNote.Sync/         # 端到端加密同步引擎、WebDAV / SMB / 本地目录传输层与三语指南
│   ├── MKNote.Migration/    # .mknote / HTML(含待办转换) / Markdown / SQLite 多格式迁移服务
│   ├── MKNote.EditorWeb/    # Vite + TypeScript + TipTap 2 + CodeMirror 6 + KaTeX + Mermaid
│   └── MKNote.App/          # WinUI 3 桌面主程序、可拖动分隔条、托盘、截图、单实例守护、系统字体
├── tests/
│   └── MKNote.Tests/        # xUnit 单元测试（加密、存储、批量删除、同步、导入导出与待办转换）
├── installer/
│   └── MKNoteNext.iss       # Inno Setup 6 Windows x64 安装包脚本
└── docs/
    └── MKNote_Next_Development_Spec.md  # 完整技术架构与开发规范文档
```

### 3. 本地开发编译与测试
```powershell
# 1. 构建离线前端编辑器（产物输出至 src/MKNote.App/Assets/EditorWeb）
cd src/MKNote.EditorWeb
npm install
npx tsc --noEmit
npm run build
cd ../..

# 2. 运行全部单元测试
dotnet test tests/MKNote.Tests/MKNote.Tests.csproj

# 3. 编译 WinUI 3 桌面端 (x64)
dotnet build src/MKNote.App/MKNote.App.csproj -c Debug -p:Platform=x64
```

### 4. 发布 Windows x64 独立安装包
```powershell
# 1. 发布自包含 Release 目录
dotnet publish src/MKNote.App/MKNote.App.csproj -c Release -r win-x64 --self-contained true -p:Platform=x64 -o dist/publish-x64

# 2. 使用 Inno Setup 6 生成安装包（输出至 dist/MKNoteNext_Setup_v1.0.0_x64.exe）
iscc installer/MKNoteNext.iss
```
