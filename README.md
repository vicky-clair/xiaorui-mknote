# MKNote Next — 本地优先加密桌面知识库

**MKNote Next** 是一款基于 **.NET 10 + WinUI 3 + SQLCipher AES-256 + WebView2** 构建的现代 Windows 桌面笔记与个人知识库软件。  
核心坚持 **100% 本地离线优先、零强制云账号、全库加密落盘（仅可通过本应用打开）**，同时内置 **富文本（HTML）** 与 **Markdown** 双文档引擎，兼顾日常图文摘录、待办清单、代码与公式记录、双链知识图谱、批量管理、智能去重导入、精准单篇/分类导出，以及端到端加密（E2EE）群晖 NAS / WebDAV 多策略跨设备同步。

---

## 一、核心功能特性

### 1. 全链路本地加密与防崩溃保护
- **整库 + 逐对象双重加密**：底层采用 **SQLCipher（AES-256）** 全库加密，同时每篇笔记正文、屏幕截图、手动插入图片、附件与全局背景图均以 **AES-256-GCM** 独立密文 BLOB 存入 `vault.db`，磁盘不生成任何明文 `.md` / `.html` / `.png` 缓存文件。
- **密钥与访问安全**：本地 256 位主密钥 `vault.key` 默认由 Windows **DPAPI**（当前用户绑定）加密保护；可选便携模式（程序同级创建 `Data/` 目录即可随身携带）。支持**本地应用锁**（PBKDF2-SHA256 + Windows Hello 生物识别/PIN + 空闲自动锁定）以及**单篇笔记独立密码加密**。
- **防崩溃恢复日志（Crash-Safe Journal）**：编辑过程中自动防抖保存并实时写入加密预写恢复日志（`recovery/*.mkr`）。即使遭遇系统断电或异常闪退，下次启动时会自动检测并无损恢复崩溃前最后输入的内容。
- **回收站隐私门禁**：移入回收站的文档默认锁定正文内容不予展示，仅允许「恢复」或「彻底删除」。
- **严格单实例运行**：通过 Win32 命名互斥量（Mutex）与命名管道（NamedPipe）禁止双开多开；重复启动时自动唤醒已在前台或托盘中的现有窗口。

### 2. 双文档引擎（富文本 + Markdown）与全宽舒适排版
- **全宽文档画布**：富文本编辑区、Markdown 源码区与阅读视图均采用全宽自适应布局，左右保留 `24px` 舒适边距并与顶部标题栏对齐，大屏阅读长文档与宽表格更通透。
- **富文本编辑器（TipTap 2 / ProseMirror）**
  - **排版与字体控制**：内置**系统字体下拉框**与**字号下拉框（12px–32px）**——**选中文本时**可对局部片段单独修改字体与字号（支持同文档多字体混排），**未选中文本时**即时调整全局默认正文并自动保存。另支持标题层级、加粗/斜体/下划线/删除线、文字颜色、4 色高亮与清除、对齐方式、待办清单、表格（增删行列）、代码块、引用与行内查找替换。
  - **实用文本处理工具（`»` 扩展栏）**：支持行升序排序、删除重复行、清除行尾空格、大小写转换、快速插入时间戳。
  - **智能粘贴与待办兼容**：从网页或外部文档复制粘贴时自动保留图片（加密入库）与待办复选框，普通文本按纯文本保留完整换行，避免杂乱样式污染。
- **Markdown 编辑器（CodeMirror 6）**
  - **三态视图切换**：支持 **行内实时预览（Live Preview）**、**左右分屏（Split）** 与 **沉浸阅读模式（Reading，`Ctrl+E`）**，阅读模式支持长文档顺畅滚动。
  - **工具栏字体与语法扩展**：工具栏内置**系统字体与字号（12px–32px）快捷切换**、H1–H3 标题、加粗/斜体/删除线/高亮、行内代码与代码块、待办复选框、双链 `[[笔记名#标题|别名]]` 自动补全与改名联动、表格、YAML Frontmatter 属性、Callout 提示卡、**KaTeX 数学公式**与 **Mermaid 流程图/时序图/架构图**。
  - **知识图谱（Graph View）**：基于 Canvas 的力导向双链关系图，支持节点筛选、拖拽缩放与双击跳转，并支持点击 **「← 返回文档」**、按 **`Esc`** 或再次点击 **「知识图谱」** 一键切回当前文档。
  - **深度 Vim 模式**：支持 Normal / Insert / Visual / Ex（`:w`、`:noh`、`:%s/旧/新/g`、`/搜索`）完整命令，底部状态栏实时显示当前 Vim 模式与按键缓冲区；支持图片左右光标辅助定位与删除。

### 3. 灵活三栏界面、深浅特色背景与系统集成
- **灵活可拖动三栏布局**：左侧导航栏、中间笔记列表栏、右侧大纲/反链/附件抽屉之间均配备原生水平双箭头（`↔`）可拖动分隔条，支持鼠标自由拖动放缩宽度，**双击分隔条**一键恢复默认宽度，并自动持久化记忆布局宽度；列表筛选栏（**全部 / MD / 富文本**）采用独立放大字号分段展示。
- **笔记本、标签与高效批量操作**：
  - 支持自由新建、重命名、删除**任意文件夹（包含默认文件夹）**；每篇笔记顶部及列表右键菜单提供**导出**、**复制到**、**移动到**、置顶、星标、删除按钮；富文本与 Markdown 均支持多标签管理与筛选。
  - 笔记列表右上角提供 **「批量多选（☑）」** 开关：支持复选框逐项多选、`Shift + 点击` 区间连选、**全选**、**反选**、**批量导出所选**、一键**事务级批量删除**（在回收站内同时支持**批量恢复**与**批量彻底删除**），处理数百篇文档零卡顿。
- **纯内存区域截图（`Ctrl+Shift+A`）**：支持多显示器高 DPI 框选截图，不落盘任何临时明文图片，直接加密入库并插入当前光标位置。
- **全库精准符号检索（`Ctrl+K`）**：跨所有文档（含长正文深处）实时检索，精准匹配特殊符号（如 `C#`、`->`、`[[双链]]`、`$100`、`==`、`::`）。
- **精准字数统计**：底部状态栏实时展示**总字数（中日韩按字计、西文/数字按词计）**，点击可查看字符数（计/不计空格）、段落数、行数及当前选区统计。
- **三语切换、深浅双态特色背景与安全系统字体**：
  - 支持 **简体中文 / English / 日本語** 一键热切换；系统字体枚举自动过滤图标/符号类字体并附加中/英/日安全回退链；
  - 提供**浅色 8 套 + 深色 8 套专属特色文档背景**（浅色：`纯净象牙白 / 护眼豆沙绿 / 温暖羊皮纸 / 清透天青蓝 / 柔雾淡雅粉 / 浅薰衣草紫 / 极简高级灰 / 静谧水鸭青`；深色：`午夜纯黑 / 暗夜墨松绿 / 烘焙咖啡棕 / 深海星空蓝 / 星云暗夜紫 / 酒红勃艮第 / 石墨高级灰 / 复古黑板青`），随应用深/浅色主题自动联动呈现；
  - 提供在浅/深色下均清晰可见的 **5 种纸张纹理**（纯色/横线/方格/点阵/纸感），并支持**全局加密背景图**（填充/适应/拉伸/平铺/居中与不透明度调节）。
- **桌面原生能力**：支持独立置顶便签窗、Windows 开机自启（静默驻留托盘）、关闭按钮最小化至系统托盘（单击托盘图标显示/隐藏主窗）。

### 4. 端到端加密同步与 4 种备份策略（群晖 NAS / WebDAV）
- **极速分层加密（`MKS2` v2）**：所有同步数据在离开本机前使用用户独立设置的 **E2EE 主同步口令**，单次同步仅执行 1 次 **PBKDF2-SHA512（210,000 次迭代）** 派生会话主密钥，再通过 **HKDF-SHA256 + 独立随机盐** 为每个文件派生专属 **AES-256-GCM** 密钥（远端仅存 `.mke` / `.mkb` 密文，同时向下兼容旧版 `MKSE` v1 密文）。
- **增量同步与健壮传输**：借助加密索引清单（`meta/manifest.mke`）跳过未变更笔记，配合 **4 路并发传输**、连接池复用、多级目录逐级 `MKCOL`、`429/502/503/504` 自动指数退避重试、重定向保留认证头、后台线程池执行、实时百分比进度条与**随时取消**按钮，二次同步秒级完成且绝不卡界面。
- **内置 4 种同步目标与三语配置向导**：
  1. **群晖 NAS — WebDAV Server**（推荐，支持 HTTPS 5006 与局域网自签名证书信任）
  2. **群晖 NAS — 局域网 SMB 共享 / 映射盘**（如 `\\192.168.1.100\homes\MKNoteSync` 或 `Z:\MKNoteSync`）
  3. **通用 WebDAV 服务器 / 云盘**（支持标准 WebDAV 协议的私有服务器与网盘）
  4. **本地目录 / 移动存储同步目录**（本地同步文件夹、U 盘或移动硬盘目录）
- **4 种同步与备份策略（在同步窗口自由切换）**：
  - **🔄 双向同步（默认，同步删除）**：两端增量合并、双端同时改动自动保留冲突副本；通过本地与远端加密删除墓碑（`sync_tombstones` / `meta/tombstones.mke`，保留 90 天）联动清理远端与其他设备的已彻底删除笔记，**彻底防止删除后再同步复活**。
  - **➕ 保留两者（只增不删）**：双端保守合并，冲突保留副本，不因删除操作清理远端文件，最大限度防误删。
  - **📤 以本地为主（单向镜像备份）**：严格以本机为准覆盖远端并自动清理远端多余或残留文件，绝不向本机拉回覆盖（执行前弹窗二次确认）。
  - **📥 以远端为主（从云端恢复）**：从远端完整拉取并覆盖本机同名笔记，同步应用远端删除记录，绝不修改远端数据（执行前弹窗二次确认）。

### 5. 智能判重导入与精准导出
- **导入（严格全一致判重 + 智能中文编码识别）**：
  - **零误伤严格判重**：导入前在内存中完成完整解析、待办复选框转换与所有内嵌图片的 `SHA-256` 链接重写，严格比对**文档格式 + 标题 + 全文及全部内嵌图片 SHA-256**（自动兼容 `\r\n` 与 `\n` 换行符差异）。仅在 100% 确认完全一致时跳过导入、不产生空分类并弹窗列出重复文档清单；正文改动 1 个字或图片变化 1 像素均正常导入。
  - **智能防乱码解码**：自动识别 UTF-8 / UTF-16LE / UTF-16BE（含无 BOM 纯中文开头长文档）及中文 GB18030 / GBK，彻底杜绝老旧中文归档导入乱码。
  - 支持 **Markdown 文件夹**、**网页 HTML 文件夹**（含相对路径图片/Base64 图片入库与原生待办复选框自动转可交互待办清单）、**单文件归档（`.mknote`）** 与 **本地 SQLite 数据库（`.db`）**。
- **导出与备份**：
  - **单篇精准导出**（3 处入口：编辑区标题栏导出按钮、笔记列表右键菜单、右上角 `...` →「备份与导入导出」）：
    - **Markdown 笔记仅导出 `.md`**（含图片时同级生成 `assets/` 目录并重写为相对路径；无图片时不建多余目录）；
    - **富文本笔记仅导出 `.html`**（生成排版美观的独立单文件 HTML5 文档，内嵌图片自动 Base64 打包进单文件，转发给他人或离线双击打开永不丢图）。
  - **指定分类笔记本单独导出**：在左侧笔记本列表右键或点击分类行右侧 `...` → **「导出此笔记本 (MD + HTML)...」**，自动按笔记格式分别导出 `.md` 与 `.html` 并还原内嵌图片（同名自动编号防覆盖）；含子笔记本时可选择「包含子笔记本（保留多级目录树）」或「仅导出当前层级」。
  - **多选批量导出与全库导出**：支持批量多选「导出所选」与全库按多级目录树导出，以及全库离线加密备份（`.mkbackup`）。导出完成后弹窗汇总并支持一键打开所在文件夹。

## 二、日常使用指南

### 1. 快速上手
1. **新建笔记**：点击左上角「新建」可创建 **Markdown**、**富文本**、**内置模板笔记**（10 套模板支持 `{{date}}` 自动展开）或**桌面便签**。
2. **界面与背景调节**：
   - 拖动三个侧边栏边缘出现 `↔` 双箭头即可调整宽度，**双击分隔条**一键恢复默认宽度；
   - 点击顶部调色板按钮可切换当前主题对应的 **8 套特色背景** 与 **5 种纸张纹理**；
   - 在编辑器工具栏直接切换**系统字体**与**字号**（富文本先选中文本可局部排版）。
3. **高效批量管理**：
   - 点击笔记列表右上角 **多选图标（☑）** → 可 **全选** / **反选** / 手动勾选 / `Shift + 点击` 连选 → 支持一键 **导出所选** 或 **删除所选**（回收站内支持 **批量恢复** 与 **批量彻底删除**）→ 点击 **完成** 或按 `Esc` 退出。
4. **单篇与分类导出**：
   - 导出单篇：点击编辑区标题栏「导出」按钮或右键任意笔记 → **「导出此笔记 (.md / .html)...」**；
   - 导出单个分类：右键左侧任意笔记本（或点击其右侧 `...`）→ **「导出此笔记本 (MD + HTML)...」**。
5. **截图与加密插图**：按 `Ctrl+Shift+A` 框选屏幕即可纯内存截图加密入库；粘贴剪贴板图片同样自动加密入库。
6. **查看与自定义快捷键**：点击右上角 `...` 菜单可打开 **「Vim 快捷键指南与自定义」** 与 **「Markdown 语法与快捷键指南」**，核心系统热键受 `ShortcutGuard` 保护不可误覆盖。

### 2. 配置群晖 NAS / WebDAV 端到端加密同步
1. 在群晖 DSM「套件中心」安装并启用 **WebDAV Server**，开启 **HTTPS（端口 5006）**，创建共享目录（如 `/MKNoteSync`）并赋予对应账号读写权限（及应用程序中的 WebDAV 权限）。
2. 在 MKNote Next 中点击右上角 `...` → **「加密同步（群晖 NAS / WebDAV）」**。
3. 填写服务器地址（如 `https://192.168.1.100:5006`）、远端目录（`/MKNoteSync`）与账号密码；局域网自签名证书请保持勾选「允许局域网自签名 HTTPS 证书」。
4. 保持开启 **端到端加密（E2EE）** 并设置 **E2EE 同步主密码**（多台电脑必须一致），然后按需选择同步策略：
   - **多台电脑日常同步**：选 **「🔄 双向同步」**（彻底删除会同步清理远端，不会复活）；
   - **仅把云端/NAS 当本机镜像备份（或想清理此前残留在远端的旧文件）**：选 **「📤 以本地为主」**；
   - **保守归档、绝不删远端文件**：选 **「➕ 保留两者」**；
   - **新装电脑/重装恢复**：选 **「📥 以远端为主」**。
5. 先点击 **「测试连接」** 验证读写权限，再点击 **「立即加密同步」**，底部实时显示进度百分比与耗时（传输中途可随时点击「取消」）。

> **局域网直连替代方案**：同一局域网下也可选 **「群晖 NAS — SMB 共享目录」**，路径填写 `\\192.168.1.100\homes\MKNoteSync` 即可高速直连同步。

## 三、重要安全与使用注意事项

1. **重装系统或换机前务必先同步或导出（极其重要！）**
   - 标准安装模式下，数据默认位于 `%LOCALAPPDATA%\MKNoteNext\Vault\`（包含 `vault.db` 与 `vault.key`）。
   - `vault.key` 默认绑定当前 Windows 账户的 **DPAPI** 凭证，**重装系统、更换电脑或重建 Windows 账户后，仅拷贝旧 `vault.db` + `vault.key` 将无法解密**。
   - **正确迁移方式**：换机或重装前请务必通过 **端到端加密同步（群晖 NAS / WebDAV）** 或 **导出全部笔记（MD + HTML 文件夹）** 完整迁出数据；若需 U 盘随身携带，请在程序同级目录新建 `Data` 文件夹启用绿色便携模式。
2. **妥善保管 E2EE 同步口令与单篇笔记密码**
   - 本软件为 100% 零知识本地加密架构，**无后台服务器、无找回密码渠道**。请使用密码管理器或离线安全方式妥善保存 E2EE 主口令与单篇加密密码；单独加密的笔记在未解锁前不会随同步上传至远端，导出时也会跳过或提示先解锁。
3. **关于同步策略切换的建议**
   - 如果你在旧版本中删掉过文件、但远端 WebDAV 仍残留旧密文，建议先用 **「📤 以本地为主」** 同步一次清理远端残留，之后再切回 **「🔄 双向同步」** 即可。
   - 切换为单向策略（以本地为主 / 以远端为主）时，点击同步会弹出二次确认框，请确认方向后再执行；若需挂后台定时自动同步，日常推荐使用「双向同步」或「以本地为主」。
4. **自动保存与单篇大容量支持**
   - 输入停顿约 0.25 秒即自动写入加密预写日志并提交数据库；图片以内容去重 BLOB 分表存储，单篇文档可安全混排大量文本、表格、代码块、公式、流程图与高分辨率图片。
5. **运行环境要求**
   - 操作系统：**Windows 10（1809 / Build 17763 及以上）** 或 **Windows 11（64 位 x64）**（当前桌面外壳基于 WinUI 3，暂仅支持 Windows x64）。
   - 运行时：系统需具备 **Microsoft Edge WebView2 Runtime**（Windows 11 已默认内置）。

### 3. 本地开发编译与测试
```powershell
# 1. 构建离线前端编辑器（产物输出至 src/MKNote.App/Assets/EditorWeb）
cd src/MKNote.EditorWeb
npm install
npx tsc --noEmit
npm run build
cd ../..

# 2. 运行全部单元测试（16/16）
dotnet test tests/MKNote.Tests/MKNote.Tests.csproj -c Release

# 3. 编译 WinUI 3 桌面端 (x64)
dotnet build src/MKNote.App/MKNote.App.csproj -c Release -p:Platform=x64
```

### 4. 发布 Windows x64 独立安装包
```powershell
# 1. 发布自包含 Release 目录
dotnet publish src/MKNote.App/MKNote.App.csproj -c Release -r win-x64 --self-contained true -p:Platform=x64 -o dist/publish-x64

# 2. 使用 Inno Setup 6 生成安装包（输出至 dist/MKNoteNext_Setup_v1.0.0_x64.exe）
iscc installer/MKNoteNext.iss

# 3. 清理中间发布目录
Remove-Item -Recurse -Force dist/publish-x64
```
